# 五子棋

瀏覽器版五子棋遊戲，純 HTML + JavaScript 實作，無需安裝任何套件。

## 功能

- **人人對戰**：兩位玩家輪流在同一台電腦上對弈
- **人機對戰**：對抗內建 AI（使用 Minimax + Alpha-Beta 剪枝演算法）
- 可選擇黑棋或白棋先手
- 勝利時高亮顯示連線棋子

## 執行方式

直接用瀏覽器開啟 `index.html` 即可，不需要伺服器或任何相依套件。

## 技術

- 棋盤以 Canvas 繪製
- AI 採用深度為 3 的 Minimax 演算法搭配 Alpha-Beta 剪枝
- 評分函數根據連子數與開口數計算棋型分數
